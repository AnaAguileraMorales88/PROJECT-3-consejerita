# Consejito del día
Una aplicación de página única (SPA) sencilla, responsiva y alegre que muestra consejos inspiradores de manera aleatoria utilizando una API externa.

## Descripción
Al hacer clic en el botón, la aplicación muestra un nuevo "consejito del día" obtenido en tiempo real desde una API.
El objetivo de este proyecto es practicar la integración con APIs, el manejo del DOM con JavaScript y la creación de una interfaz limpia y adaptable.

## Funcionalidades

🔄 Obtiene consejos aleatorios desde una API externa.

📱 Diseño adaptable a diferentes tamaños de pantalla (responsive design).

🎨 Logo a la izquierda y título centrado.

💻 Código limpio, semántico y simple.

⚡ Interacción fluida sin recargar la página (SPA).

## Tecnologías utilizadas

HTML5 → Estructura semántica y accesible.

CSS3 → Estilos responsivos, tipografía y colores.

JavaScript (Vanilla) → Lógica principal, conexión con la API y manipulación del DOM.

Figma → Diseño de interfaz y prototipado.

Visual Studio Code → Entorno de desarrollo.

Trello → Gestión de tareas y organización del trabajo.

Git / GitHub → Control de versiones y colaboración.

## Instalación y uso

1. Clona este repositorio:
git clone https://github.com/AnaAguileraMorales88/PROJECT-3-consejerita.git

2. Abre el proyecto en tu editor de código (por ejemplo, Visual Studio Code).

3. Abre index.html en tu navegador.

4. Haz clic en el botón para obtener un nuevo consejito ✨
